# Visitor Counter icon

`computer-vision-source.png` is the original generated artwork. Desktop sizes are generated with Tauri CLI:

```sh
cargo tauri icon src-tauri/icons/computer-vision-source.png --output /tmp/visitor-counter-icons
```

Copy the desktop PNG, ICO, and ICNS files into this directory. Mobile outputs are not used.

Created using the built-in imagegen tool. Prompt: desktop application icon for a CCTV computer vision and people counting application; optical lens with detection corner brackets and a human silhouette; midnight blue rounded tile with cyan and teal highlights; legible at small sizes; transparent outside the tile; no text or watermark.
